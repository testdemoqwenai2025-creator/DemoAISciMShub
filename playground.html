Demo 1 · Testing suite

E(3) Rotational Invariance Tester

Generates a synthetic 3D point cloud, runs an EGNN forward pass to produce displacements, then rotates the input by a random E(3) transformation and runs the forward pass again. The displacements should be identical (modulo the rotation). If they are not, the network is not E(3)-equivariant — and OSIRIS's entire safety case fails.

What these tests prove — and what they don't

The E(3) rotational invariance tester proves that the EGNN layer is structurally equivariant — not just empirically. If you rotate the input by any R ∈ O(3) and translate by any t ∈ ℝ³, the output transforms identically. This is a property of the architecture, not the weights. It holds for any trained model, including the untrained random-weight model in this demo.

The 3D ConvTranspose voxel decoder proves that the splatting step preserves the Theorem 7 bound — every voxel in the output volume is traceable to a token whose cumulative displacement is ≤ L·c. This is what makes the output certifiable for medical / climate / space deployment.

What these tests do not prove: that the model is accurate, that the training data was representative, that the deployment will generalize to out-of-distribution inputs. Those require empirical evaluation on real datasets (EMPIAR, ERA5, JWST MAST) — see the /datasets page.
