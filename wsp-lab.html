SECTION 01

Claim → Classifier

The platform already extracts a paper's structure into a weighted concept graph and key-claim popups. This section closes the loop: pick a key claim and it seeds a runnable zero-shot classifier for that claim's modality — a set of convolutional kernels (the "described features" cast into weight space) and preset weights (the LLM's reading of how strongly each feature speaks for the claim). A sample image is convolved, pooled, and scored. No labelled corpus is used; the only supervision is the claim itself. Drag the weight sliders to reprogram the classifier in real time.

    SECTION 02

    Cross-Domain WSP

    Weight-space programming is not a medical trick. The same recipe — described features become kernels, the LLM sets the weights, a forward pass scores the image — transfers to any imaging modality with a usable description. Here it runs on satellite and materials imagery that have nothing to do with the medical claims above. Same engine, different preset, different sample generator. This is the proof the method is a general zero-shot tool, not a domain-specific artefact.

      SECTION 03

      Safety & Calibration

      The SynthUterus failure — a model that scored 0.952 on held-out samples while the true correlation with the described feature was r = 0.136 — is the reason this section exists. A confident score is not evidence. Here, the current classifier is run on three held-out probes (a positive control, a negative control, and an ambiguous edge case) and the Pearson correlation between score and expected label is computed. If that correlation falls below a refusal threshold, the system refuses to emit decision support and a human-in-the-loop gate stays locked. Use the Sabotage button to invert the weights and watch the gate slam shut.

      SECTION 04

      Real-Data Runner

      The final recommendation was a real-data runner with inspectable weights. Rather than ship a Pyodide dependency, this section implements a small but genuine CNN forward pass in plain JavaScript — conv(3×3) → relu → maxpool(2) → global-avg → dense(3→1) → sigmoid — on real-like sample images. Every kernel is shown as an editable matrix and every dense weight is editable; change a value and re-run to see the activation maps and score update. The weights are the WSP preset for the selected claim; nothing here was trained.
