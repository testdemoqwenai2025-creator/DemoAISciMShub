Computational stack

The modern computational tools we ship.

Every tool below is free and open source. Most are loaded in-browser via Pyodide or CDN — no install, no signup. The heavyweight frameworks (PyTorch, JAX, Dask) ship with the reference engine and run on CPU. No proprietary dependencies, no SaaS lock-in, no vendor SDK.

Pyodide — Python in WebAssembly

in-browser

In-browser execution

CPython compiled to WebAssembly. Runs scientific Python (NumPy, pandas, scipy, scikit-learn, matplotlib) entirely in the browser with zero backend. The execution backend for our in-browser IDE studio.

Powers the /ide page. No external service required — Python runs in your browser tab.

MPL-2.0 + MIT

JupyterLite — Jupyter in WASM

in-browser

Notebook environment

JupyterLab compiled to WebAssembly. Read+write .ipynb notebooks entirely in the browser, served from a static site. The kernel is Pyodide. Used on our /notebooks page.

Powers the /notebooks page. Notebooks persist to browser storage; can be exported and shared.

BSD-3-Clause

How it fits together

The stack is layered: a free public dataset (EMPIAR / ERA5 / JWST MAST) feeds a thin adapter, which feeds the TME-FUSE engine (PyTorch CPU or JAX), which produces a 3D volume / map / spectrum with calibrated uncertainty. Users can write Python in the in-browser IDE (Monaco + Pyodide) or in a JupyterLite notebook to ingest the same data, call the same engine, and reproduce the same numbers.
