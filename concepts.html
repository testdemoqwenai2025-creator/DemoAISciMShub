How concept cards work

Click any card above to open the full concept card as a popup. Inside, six tabs let you navigate from the abstract math to the runnable code, the 3D-to-ND animated observation, the strategic deep-thoughts, the comparison with related approaches, and the futuristic possibilities over the next decade. The 🧠 Deep Thoughts tab has an "Ask AI" button that uses the z-ai-web-dev-sdk to derive additional strategic guidance on demand (rate-limited to 8 requests/minute).

📐 Math tab

Each math stage shows the formula, a plain-ASCII rendering, an explanation, and a variable table with units. The 5-stage pipeline diagram has play/pause/step controls.

💻 Code tab

Runnable Python with explicit Math→Code mapping comments above each function. One-click copy. "Open in IDE studio" deep-link to run the code in your browser via Pyodide.

📊 Observations tab

3D-to-ND animated HTML5 canvas — no Three.js, no external deps. Renderer types: rotating-points (3D), time-series (4D), size+color (5D), ND projection (8D). Play/pause + progress %.
