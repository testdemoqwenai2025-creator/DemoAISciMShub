Research deep-dive · OpenAI × PerturbAI × Scripps · 2026-10-21

Thousands of AI agents
32 minutes · millions of brain cells · 700+ references

OpenAI, PerturbAI, and Scripps Research used thousands of GPT-Rosalind AI agents to analyze experimental data from millions of mouse brain cells in just 32 minutes. The agents connected gene disruption effects with scientific literature, uncovering unexpected biological connections (e.g., cholesterol regulation → neuronal function) that could help scientists understand diseases like Alzheimer's and Parkinson's. This page breaks down the research into 7 interactive demos with math, code, observations, deep thoughts, and futuristic visions.

💻 Runnable code

import openai
# GPT-Rosalind multi-agent system
N_AGENTS = 1000  # thousands of agents
genes = crispr_atlas.get_disrupted_genes()  # millions of cells

agents = [openai.Agent(model="gpt-rosalind") for _ in range(N_AGENTS)]
reports = []
for gene in genes:
    # Each agent analyzes one gene's disruption effect
    # + connects to scientific literature
    report = agents[i % N_AGENTS].analyze(
        gene_disruption=gene,
        literature=openai.literature_search(gene.name),
        cell_type=gene.affected_cell_types,
        brain_region=gene.brain_region,
    )
    reports.append(report)

# Combine into reasoning atlas
reasoning_atlas = aggregate(reports)
print(f"Agents: {N_AGENTS}, Reports: {len(reports)}")

💻 Runnable code

import numpy as np
# Whole-brain CRISPR atlas
# Each gene disruption affects specific cell types in specific brain regions
atlas = load_crispr_atlas()  # millions of mouse brain cells
genes = atlas.genes  # ~20,000 genes
regions = atlas.brain_regions  # ~300 regions
cell_types = atlas.cell_types  # ~100+ types

# For each gene, find affected cell types per region
disruption_matrix = np.zeros((len(genes), len(regions), len(cell_types)))
for g, gene in enumerate(genes):
    for r, region in enumerate(regions):
        affected = atlas.query(gene=gene, region=region)
        for ct in affected:
            disruption_matrix[g, r, ct] = 1

print(f"Disruption matrix: {disruption_matrix.shape}")
print(f"Total disruptions: {disruption_matrix.sum()}")

📊 Observation

3D heatmap showing gene × brain_region × cell_type disruption matrix. Genes on Y-axis, brain regions on X-axis, cell type affected as color intensity. Bright spots indicate genes that disrupt many cell types across many regions — these are the high-impact targets for disease research.

Use when

  • When you need to understand which genes affect which cell types in which brain regions
  • When the CRISPR atlas has millions of cells (too large for manual analysis)
  • When you want to identify high-impact gene targets for drug development

Avoid when

  • When the atlas is incomplete or has systematic biases (e.g., only cortical regions)
  • When cell type annotations are unreliable (need validation)
  • When the species gap (mouse → human) hasn't been characterized

Why

  • The CRISPR atlas provides causal evidence (gene disruption → phenotype), not just correlation
  • Whole-brain coverage ensures no region is missed — critical for diseases like Alzheimer's that affect multiple regions
  • Cell-type resolution enables targeted therapy (affect only the affected cell types, not all neurons)

💻 Runnable code

# Connect gene disruption effects to scientific literature
from openai import GPT_Rosalind

agent = GPT_Rosalind()
gene = "SCN2A"  # sodium channel, disrupted in atlas

# 1. Get disruption phenotype from CRISPR atlas
phenotype = atlas.get_disruption_phenotype(gene)
# e.g., "reduced excitability in cortical pyramidal neurons"

# 2. Search literature for related findings
papers = agent.literature_search(
    query=phenotype,
    filter=["neuroscience", "genetics", "pharmacology"],
    max_results=50,
)

# 3. Score and rank by relevance
ranked = agent.rank(papers, by="relevance_to_phenotype")
print(f"Top paper: {ranked[0].title}")
print(f"Relevance score: {ranked[0].score:.3f}")
print(f"Total papers found: {len(ranked)}")

💻 Runnable code

# Compare distributed (1000 agents) vs single agent
import time

# Single agent
single_agent = GPT_Rosalind()
t0 = time.time()
single_report = single_agent.analyze(gene, literature)
t_single = time.time() - t0
single_refs = len(single_report.references)  # ~11

# Distributed (1000 agents)
t0 = time.time()
distributed_reports = [agent.analyze(gene, literature)
                       for agent in agents[:1000]]
t_distributed = time.time() - t0
distributed_refs = sum(len(r.references) for r in distributed_reports)  # ~700

print(f"Single: {single_refs} refs in {t_single:.1f}s")
print(f"Distributed: {distributed_refs} refs in {t_distributed:.1f}s")
print(f"Ratio: {distributed_refs / single_refs:.1f}× more coverage")

💻 Runnable code

# Expert preference validation
import numpy as np
from scipy import stats

# Expert panel evaluated both report types
n_experts = 20  # expert panel size
prefer_distributed = 15  # 75%
prefer_single = 5  # 25%

# Binomial test: is 75% significantly different from 50%?
result = stats.binomtest(prefer_distributed, n_experts, p=0.5)
print(f"Distributed preference: {prefer_distributed}/{n_experts} = {prefer_distributed/n_experts:.0%}")
print(f"p-value: {result.pvalue:.4f}")
print(f"Significant: {result.pvalue < 0.05}")

# 95% confidence interval
ci = result.proportion_ci(confidence_level=0.95)
print(f"95% CI: [{ci.low:.2%}, {ci.high:.2%}]")
