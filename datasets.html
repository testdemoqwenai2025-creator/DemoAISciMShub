How AISciImg360 uses these datasets

Every modality skill in AISciImg360 declares its primary dataset (for input), its baseline dataset (for benchmark comparison), and an alternative dataset (for cross-domain validation). The dataset links above are the same sources the platform ingests at runtime — there is no private curated subset. If a user wants to reproduce a benchmark, they download the same data from the same public source.

To keep browser popups fast and the page itself responsive, only the first 8 datasets render at a time. Clicking "Load 8 more" expands the next batch — this is the lazy-evaluation pattern that the whole platform follows.
