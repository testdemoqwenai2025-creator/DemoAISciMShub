# OSIRIS — Downloads

This directory contains downloadable artifacts from the OSIRIS / AISciImg360 project.

## 20-Year Vision Document

- [`PLANNING.md`](./PLANNING.md) — Comprehensive 20-year vision document
  covering mission, intellectual foundation, skills inventory, research
  agenda (modern papers + GitHub repos), computational tooling stack,
  6-phase roadmap, workflow choreography, architecture constraints,
  and open questions. Authored 2026-10-24.

## Concept Card Notebooks

Each of the 31 concept cards has an on-the-fly `.ipynb` notebook generator
in the live app — click any card on the [Concept Cards page](../concepts.html)
and use the "Download .ipynb" button in the Code or Observations tab.
