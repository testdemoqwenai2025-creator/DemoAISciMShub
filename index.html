Compliance & legal

GDPR

Personal data is processed lawfully, minimally, and transparently. For EU deployments set AISCIIMG360_DATA_REGION=eu. Data subject requests honored via audit log replay.

HIPAA

For medical imaging workflows set AISCIIMG360_PHI_MODE=safe_harbor. The 18 HIPAA identifiers are redacted by default. PHI never leaves the user's environment.
