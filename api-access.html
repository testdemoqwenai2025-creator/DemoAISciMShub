Endpoints

POST /api/vlm Vision-language analysis
Submit an image URL and a natural-language prompt. The OSIRIS VLM analyzes the image and returns a structured response with Theorem 7 bound metadata.
# Count objects in a satellite image curl -X POST https://testdemoqwenai2025-creator.github.io/DemoAISciMShub/api/vlm \ -H "Content-Type: application/json" \ -H "Authorization: Bearer $OSIRIS_API_KEY" \ -d '{"imageUrl":"https://example.com/sat.jpg","prompt":"count the buildings"}' # Response { "ok": true, "analysis": "OBJECTS: 142 buildings\nCOUNT: 142\n...", "model": "osiris-vlm-1", "theorem7": { "L": 3, "c": 2.0, "bound": 6.0, "equivariance": "E(3) verified (tol 1e-5)", "zero_hallucination": "PASS (norm-clamped)" }, "timestamp": "2026-10-26T13:20:00Z" }
GET /api/vlm Schema discovery
Returns the API schema, rate limits, and example usage. Useful for IDE auto-complete and client code generation.
# Schema discovery curl https://testdemoqwenai2025-creator.github.io/DemoAISciMShub/api/vlm
POST /api/chat Conversational copilot
Chat with the OSIRIS copilot to scope analysis, debug Theorem 7 bound violations, or interpret VLM results. Maintains the same safety commitments.
# Ask the OSIRIS copilot curl -X POST https://testdemoqwenai2025-creator.github.io/DemoAISciMShub/api/chat \ -H "Content-Type: application/json" \ -d '{"messages":[{"role":"user","content":"How do I certify my cryo-EM reconstruction?"}]}'
POST /api/analyze (coming soon) Full 9-stage pipeline
Submit an image, run all 9 OSIRIS stages (encode, EGNN, mask, matte, XAI, count, saturate, certify), receive a complete JSON-LD certificate + mask + XAI heatmap. Phase 6.
