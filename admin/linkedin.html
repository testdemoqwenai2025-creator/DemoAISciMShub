LinkedIn's API is gated, but public posts have an og:description meta tag. Paste a URL below — the system fetches the post text server-side, extracts cited paper DOIs, and drafts a concept card skeleton. You review and publish. By v0.3.0 this becomes a community "Research Feed" of sourced cards.

Step 1: paste LinkedIn post URL

The URL must point to a public LinkedIn post (no auth wall). The scrape fetches the post page server-side and parses the og:description meta tag.

How LinkedIn ingest works

  1. You paste a LinkedIn post URL into the input above.
  2. Server-side fetch to LinkedIn (no auth) — the page returns the post's og:description meta tag (typically the post text).
  3. Extract paper DOIs via regex (matches 10.\d4/\S+ pattern).
  4. Extract candidate keywords from the post text — common imaging terms (cryo-EM, equivariant, EGNN, TME-FUSE, etc.) are detected and matched to OSIRIS concept card IDs.
  5. Draft a concept card skeleton with title, inspiration, suggested pipeline stages, keywords, and Python code stub.
  6. You review + edit + publish. The card goes into the drafts queue.
  7. By v0.3.0: a "/admin/research-feed" page shows all published community-sourced cards, ranked by citation count and reproduction status.
